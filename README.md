# Dedsafío Sammy Edition — Descargas

Aquí están el **launcher** y el **mod** de Dedsafío Sammy Edition para Minecraft Java 26.2.

## Cómo jugar
1. Ve a **Releases** y baja **DedsafioSammyEdition-Instalador.exe** (o el `.zip` si no quieres instalar nada).
2. Ábrelo, escribe tu nombre y dale a **JUGAR**.
3. La primera vez tarda un poco: descarga Minecraft, Fabric, Java y el mod. Después solo baja lo que cambie.

El launcher se actualiza solo con cada versión nueva del mod.
